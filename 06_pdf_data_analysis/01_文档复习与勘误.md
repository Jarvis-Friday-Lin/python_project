# 文档复习、范围与勘误

## NumPy：学习后应能口头解释

| 问题 | 参考回答 | 对应章节 |
|---|---|---|
| ndarray、shape与ndim分别是什么？ | 数组对象、各轴长度元组、轴数量。这里维度指轴数量，不是线性代数中的矩阵秩。 | 01—02 |
| zeros/ones/full/eye分别生成什么？ | 零、全一、固定值、单位矩阵；先明确shape和dtype。 | 03 |
| 为什么arange(20,61)包含60？ | stop右端不包含，所以整数末尾60需要stop=61。 | 04 |
| dtype为什么重要？ | 决定可表达的数值、精度、范围和每格内存。 | 05 |
| 基础切片与高级索引差别是什么？ | 基础切片通常为视图，高级索引读取返回副本。 | 06—08、14 |
| 广播兼容怎么判断？ | 从右往左逐轴比较，相等或一方为1才兼容；缺少的左轴视为1。 | 15 |
| 广播会真复制小数组吗？ | 通常不建立显式重复的小数组，但运算结果和中间结果仍可能分配大量内存。 | 15、18 |
| 点积与逐元素乘有什么区别？ | 一维点积将对应乘积求和为标量；逐元素乘保留各位置乘积。 | 16 |
| reshape、transpose、增轴分别做什么？ | 重分组、改变轴顺序、插入长度1的轴，不是同一个操作。 | 12—13 |
| 为什么一维数组T后shape不变？ | 它只有一根轴，没有两根轴可交换。 | 12 |
| mean(axis=0)为何是科目均值？ | 此案例第0轴是学生，跨学生汇总后留下科目。 | 10 |
| 视图会影响原数据吗？ | 修改共享元素可能影响；copy用来隔离试算。 | 14 |
| 如何算两集合两两距离？ | 扩成(M,1,D)和(1,N,D)，差平方沿D求和再开方，得到(M,N)。 | 18 |
| NumPy为什么常对批量数值更高效？ | 定型缓冲区与底层批处理降低Python循环和对象开销，实际成本要含转换与中间内存。 | 18 |
| 文档末尾27题在哪里？ | 02_numpy/19_PDF原题自测：题目包含所有输入，答案含逐项断言。 | 19 |

## Pandas：学习后应能口头解释

| 问题 | 参考回答 | 对应章节 |
|---|---|---|
| Pandas适合什么？ | 有字段含义、行列结构的数据整理与分析。 | 01 |
| Series与DataFrame？ | 带标签的一维数据与二维表。DataFrame各列可用不同dtype。 | 01—03 |
| Series可以从哪些数据建立？ | 列表、字典、NumPy数组；index与name提供身份和字段含义。 | 02 |
| loc与iloc的依据？ | 标签与位置；一般有序唯一标签切片包含末标签，位置切片不含终点。 | 02、05 |
| 如何访问index、values与columns？ | 属性访问无需括号；转换NumPy优先用显式to_numpy()。 | 02、04 |
| 如何修改指定记录？ | data.loc[行条件,列名]=新值，一次定位；避免链式赋值。 | 07 |
| 掩码是什么？ | 与选择对象对应的布尔序列，True表示保留；多条件用&、\|、~。 | 06 |
| 选一列返回什么？ | data["x"]是Series；data[["x"]]保留DataFrame。 | 01、05 |
| 对齐为什么产生NaN？ | 标签只有一方拥有时没有匹配值，不能假定另一方是0。 | 09 |
| mean/std/min/max/sum做什么？ | 聚合统计；DataFrame默认按列，注意数值列与标准差口径。 | 10 |
| read_csv与to_csv需要关注什么？ | 分隔符、说明行、表头、缺失标记、编码以及是否保存索引。 | 11 |
| 缺失如何检测和处理？ | isna/isnull、notna/notnull；按业务使用dropna或按列fillna。 | 12—13 |
| groupby返回什么？ | 分组对象；再聚合为结果表，reset_index可把键还原成列。 | 14 |
| count与size有什么差别？ | count数非缺失值，size数记录数或格子总数，取决于对象。 | 10、14 |

文档开头提到透视表和探索性分析，但没有详细展开所有相关API；本套不把merge、透视表或时间序列扩成必修。重复订单检查等用于综合案例时会明确标注为补充。

## 原文需要特别注意的地方

- NumPy第66页 `no.full` 是笔误，应该是 `np.full`。
- NumPy的“rank”在这份入门资料中指ndim，不能与 `np.linalg.matrix_rank` 混为一谈。
- NumPy第36页reshape是否共享内存取决于布局；课程用 `np.shares_memory` 验证，不承诺永远是视图。
- NumPy第14页某些高精度dtype随平台而异；课程用常见int32/float64，不假定float128到处可用。
- Pandas第9页对Series切片视图的描述不能推广到所有索引和版本；需要修改原表时显式loc赋值，需要隔离时copy。
- Pandas第12页称每列名唯一，这是良好设计但不是库强制保证；Pandas允许重复列名，课程使用唯一列名避免选择歧义。
- Pandas里None/NaN、dtype变化与性能关系并非任何数据上都一样；课程通过原值、转换值、可空整数分别展示。
- NumPy的std默认ddof=0，Pandas的std默认ddof=1；对照结果必须统一口径。
- Matplotlib第24页文字中的“triangulate参数”不宜照抄成API关键字；示例采用 `Triangulation(x,y)` 对象传入 `tricontour`。
- Matplotlib第20页提到颜色定制，实际boxplot应使用boxprops/medianprops等属性字典；版本变化时先看所用版本的参数。
- 中文字体必须实际可用；课程检测本机字体，缺少时用英文图中文字，避免产生乱码方框。
- 本套在Python 3.12.4、NumPy 2.5.5、Pandas 3.1.1、Matplotlib 3.11.2上运行验证；与PDF标注版本不同。Pandas 3.1对DataFrame.drop的inplace参数发出弃用提示，示例保留这一旧式调用用于理解PDF，新代码使用返回新表的方式。
