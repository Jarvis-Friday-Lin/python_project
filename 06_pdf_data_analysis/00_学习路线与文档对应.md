# 从三份 PDF 学会 Python 数据分析

按 01 → 02 → 03 → 04 → 05 的顺序学习。共 53 个知识点/案例目录，其中 NumPy 第19节用于覆盖文档末尾27道操作题。

## 第一次打开项目

1. 在 PyCharm 中打开工程 `/Users/linqingling/python`。
2. 选择 Python 3.10 或更新的解释器；建议为本套课程使用独立虚拟环境。
3. 在 PyCharm Terminal 中安装本目录的依赖：`python -m pip install -r 06_pdf_data_analysis/requirements.txt`。
4. 如果已创建本课程 `.venv`，可直接将 `06_pdf_data_analysis/.venv/bin/python` 设为项目解释器。
5. 从 `01_基础准备/01_数据容器与遍历/01_examples.py` 开始，右键 Run。绘图脚本运行后可在 Plots 工具窗或弹出窗口看图。

不需要联网取数、登录账号或使用股票行情。课程数据全部在本地，模拟案例不冒充真实业务数据。

首次安装依赖需要网络。需要复现本次验证环境时，改用本目录的requirements-tested.txt安装；PDF里的库版本与本机验证版本不同，相关差异在勘误中说明。

## 每一节怎么读

- `01_examples.py`：从具体任务出发，先看路线，再逐段读代码附近的说明。可以设断点观察中间对象。
- `02_exercises.py`：完整的数据表与本题要求已经提供；需要你自己写创建对象、计算、筛选或绘图的代码。
- `03_answers.py`：每题的参考实现、结果验证与易错点。先做题，再对照。
- 示例末尾的四个问题先自己回答，参考答案紧接在下方，以注释保存，不强制弹窗或等待键盘输入。

### 示例与练习的区别

53节练习已全部改为迁移应用：考查同一知识点，但使用不同于 examples 的场景、数据和业务问题，不再把示例代码挖空作为练习。每份题面都附完整注释表格，由学生自行创建列表、数组或表格；参考答案与该份新题的数据和要求对应。

每节的“课件核心”注明原PDF所讲内容；“扩展”标出原课件未系统展开的参数、前置知识和组合应用。基础准备属于前置补充，不冒充课件原内容。`assert`、`array_equal`、`allclose`、图形对象读取等验证工具用于自查，不作为新增的课件必考内容。

先做基础任务，再做应用任务；明确标为扩展的任务可以在理解核心后再完成。NumPy第19节保留原27题的知识点顺序，但采用变式输入；目录名保持不变以免破坏已有导航。请以新题面为准，不沿用示例中的数据或答案。

完整逐节新题、PDF页码及扩展说明见：[迁移练习与课件对应清单](./02_迁移练习与课件对应.md)。练习输出均在各节 `outputs` 下；旧 `datasets` 保持原样，继续供示例使用。

## 数据与输出

`datasets/` 存放附带的固定 CSV，练习要求中的表格与文件内容对应。
需要写文件的章节只写到本节 `outputs/`；不会覆盖 `datasets/` 或你原来课程的文件。
脚本通过自身文件位置定位数据，所以从工程根目录或任意工作目录运行都可找到文件。
图表会保留在窗口里供你看；关闭窗口后脚本才继续结束，这是正常行为。

## 学习检查

一节学完应能：换一组输入重算、解释参数和结果类型、说清边界条件、比较替代实现。
先确保数值和范围正确，再考虑简写。性能示例仅报告本机测试，不承诺固定加速倍数。
原资料明显笔误与表述边界见 [01_文档复习与勘误.md](./01_文档复习与勘误.md)。

`tools/verify_course.py` 用于批量运行示例和答案，采用无界面绘图后端并检查文件结构、分隔符及题目数据。它不替代你对照图像与逐段理解。
